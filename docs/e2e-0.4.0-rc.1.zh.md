# E2E 验证记录：dsh 0.2.1-rc.2 真机（2026-10-20，0.4.0-rc.1）

> 本轮在**隔离 home**里验证 0.4.0-rc.1 的本实例自用工具：同一套 24 个 MCP 工具以
> `carrot_` 前缀注册到宿主 `ctx.tools`，并在 `dsh_list_tools` / `dsh_status` 中可见。
> 使用 `scripts/e2e-isolated.mjs` 创建临时 profile、装 link 插件、启动独立宿主（MCP 8095），
> 再跑 `test/e2e.ts`；本轮跑零 token 相。

## 环境

-   宿主：`@deepseek-ai/dsh@0.2.1-rc.2`（本机桌面发行版，`ELECTRON_RUN_AS_NODE=1` 启动 CLI）
-   隔离 home：`mkdtemp(os.tmpdir()/dsh-carrot-e2e-*)`；只复制 `.credentials.yaml` 与
    `settings.yaml.imported`，验证完保留临时目录供检查
-   profile：`carrot-e2e`，`--from-default-profile web` 重建；插件经
    `dsh plugin --profile carrot-e2e add link:<仓库>` 安装
-   MCP 端口 8095（避开常驻实例 8090 与 smoke 端口）
-   客户端：`test/e2e.ts`（零 token 相）

## 结果

-   `initialize` 上报 version **0.4.0-rc.1**；`tools/list` 仍为 **24 个 MCP 工具**。
-   `dsh_list_tools` 的全局表出现 **24 个 `carrot_*` 原生工具**，包含
    `carrot_session_create` / `carrot_dsh_status` 等；其它宿主全局工具 1 个，共 25 个。
-   `dsh_status` 回报 `config.selfToolsEnabled=true`、`stats.selfTools=24`。
-   其余零 token 相（echo / 入门指南 / 模型目录 / 工作区 / 会话清单 / 审批只读 / 资源面）
    全部通过。

## 说明

-   本轮没有跑 `E2E_WITH_AGENT=1` 的真实 turn；原生工具的执行路径由 `test/smoke.ts` 的
    158 项断言覆盖（桩宿主），全局注册与 `ctx.tools` 可见性由上面的真机零 token 相覆盖。
-   常驻 web profile 本轮没有走 HMR 重载（`startedAt` 未变，status 仍为 0.3.0-rc.1）；
    新宿主代码需要重启 profile 或重载插件后才会在该实例生效。隔离宿主是新启动的，
    因此不受影响。
-   临时 home 保留在 `%TEMP%` 下；脚本不会自动删除，便于复查。
