## Rice on a Stick (白饭钓竿)

This dsh deployment runs the Rice on a Stick plugin (package `dsh-rice-on-a-stick`): the
`rice_*` tools belong to it, and they drive this same dsh process — sessions (send, poll,
fetch results, queue, slash commands), approvals and questions, the model and permission
catalogs, and a raw dsh-endpoint escape hatch. When a user mentions 白饭钓竿 or Rice on a
Stick, they mean this plugin.

`rice_dsh_guide` with no arguments returns the guide's section index (concepts, workflows,
errors, results, limits); read the matching section before a non-trivial session or
approval workflow rather than guessing.
